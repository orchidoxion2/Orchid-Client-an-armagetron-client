# Orchid Client

A modified [Armagetron Advanced](https://gitlab.com/armagetronad/armagetronad) client for Linux.

## Download and play

1. Download [orchid-client-linux-x86_64.tar.gz](https://github.com/orchidoxion2/Orchid-Client-an-armagetron-client/raw/main/orchid-client-linux-x86_64.tar.gz).
2. Unpack it:
   ```bash
   tar -xzf orchid-client-linux-x86_64.tar.gz
   ```
3. Start the game:
   ```bash
   ./orchid-client/AppRun
   ```
4. Optional: add Orchid Client to your app menu, so you can search for it with the Windows key:
   ```bash
   ./orchid-client/install-launcher.sh
   ```
